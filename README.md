## 运行

```powershell
npm.cmd install
npm.cmd start
```

## 当前能力

- 无边框、透明、置顶的桌面窗口
- 点击 `＋`，或从资源管理器、浏览器网页拖入多张图片
- 网页拖入同时兼容文件、图片 URL、HTML 图片标签和 DownloadURL
- 抠图后只保留最大的连续主体，清除外围散落像素
- 主体边缘自动羽化，并生成一圈半透明高光“塑料框”
- 单击图片选中，使用 `⌫` 或键盘 Delete 删除
- 使用 `✂` 打开手动抠图，可用擦除笔、恢复笔和自动重抠
- 抠图强度位于抠图编辑器，不占用容器设置
- 选中图片时才显示独立图片面板，可调整到 40%–180%
- 塑料框宽度可按图片调整为 1–32 像素
- 容器设置可指定新导入图片的默认大小与默认塑料框厚度
- 当前原最大值 16 作为新的默认中间值
- 按半透明外框生成凸包碰撞体，外框可相互接触但不会重叠
- 保留轮廓干净的汽水瓶和展示盒两种容器
- 自定义容器颜色
- 可用滑块或“小 / 中 / 大”预设平滑调整容器宽高
- 窗口边缘缩放已锁定，晃动容器不会再意外改变尺寸
- 点击锁形按钮启用鼠标穿透；可点击独立的半透明小锁或按 Ctrl+Shift+L 解锁
- 图形化瓶子库可命名并保存多个场景、更新当前、删除或选择展示
- 下次启动自动恢复最后展示的瓶子；旧单瓶存档会自动迁移
- 可直接拖动容器内的图片调整位置，松手后恢复重力与碰撞
- 保存和锁定按钮使用对齐的 CSS 图形图标
- 锁定后的独立解锁按钮进一步降低了背景、边框和图标不透明度

## 无终端启动

依赖安装完成后，双击 `ShakePet.vbs` 可静默启动，不会保留命令行窗口。`start.bat` 现在也会在启动 Electron 后立即退出。
- 按住容器空白处或顶部标题拖动整个窗口
- 重力、弹性、摩擦、旋转和边界碰撞
- 拖动窗口时根据运动变化给图片施加惯性
- 可调整窗口大小、关闭或暂停重力

所有抠图都在本机完成，不会上传图片。自动抠图适合纯色或接近纯色背景，复杂背景可进入手动编辑器修整。场景保存和开机启动计划在下一阶段加入。
