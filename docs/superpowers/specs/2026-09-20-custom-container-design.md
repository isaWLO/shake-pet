# 自定义容器设计

## 目标

用户在独立的大编辑窗口中导入 PNG，通过魔棒、画笔和橡皮定义一个连续的“允许图片移动区域”，保存后立即作为桌面容器使用，并随瓶子场景一起保存和恢复。

## 已确认范围

- 第一版只支持一个连续活动区域。
- 魔棒按点击像素和容差选择相邻区域。
- 画笔添加区域，橡皮删除区域；提供笔刷大小、撤销和重置。
- 保存前填平内部小孔、删除零散区域，只保留最大连通区域。
- 不放置测试图片，不提供编辑器内物理预览。
- 支持用户 PNG 外观，也内置一张原创珍珠粉蛋形游戏机 PNG。
- 不新增第三方依赖。

## 交互

容器设置增加“绘制自定义容器”。点击后打开约 900×700 的独立窗口，默认显示内置粉色游戏机；用户也可以导入自己的 PNG。画布把允许区域显示为半透明蓝色覆盖层。

工具只有：导入 PNG、内置样式、魔棒、画笔、橡皮、容差、笔刷大小、撤销、重置、取消、保存。保存时如果活动区域过小或不存在，直接提示并保持编辑器打开。

## 数据与算法

编辑器使用与原图同尺寸的二值蒙版。保存时将蒙版缩小到最多 160×160 的工作网格，保留最大四连通区域并填孔，然后沿单元格边界提取封闭外轮廓，再简化到最多 96 个点。轮廓点和安全落点都归一化到 0–1。

场景格式升级为 version 2：

```js
container: {
  shape: 'custom',
  custom: {
    name: '珍珠粉游戏机',
    skinDataUrl: 'data:image/png;base64,...',
    polygon: [[0.2, 0.2], ...],
    spawn: [0.5, 0.5]
  }
}
```

旧版 bottle/box 场景保持兼容。自定义 PNG 不写入偏好设置，只随瓶子场景保存，避免 localStorage 容量问题。

## 渲染与物理

归一化轮廓按当前窗口宽高映射。每条边沿用现有 Matter.js 静态墙体生成方式；无需像素级碰撞。图片、音频波形限制在轮廓内部，PNG 外壳在图片之后绘制，使按钮和边框自然遮住越过内沿的部分。

容器切换或缩放后，若图片中心落到轮廓外，则移动到保存的安全落点，再交给 Matter.js 分离重叠。窄于图片的局部区域不承诺可进入；物理墙体会阻止图片穿出。

## 错误边界

- 无有效活动区域：拒绝保存。
- 零散涂点：自动丢弃。
- 内部孔洞：自动填平。
- 损坏或缺失的自定义数据：恢复为汽水瓶，不让应用崩溃。
- 图片读取失败或超过现有图片选择能力：显示错误，不覆盖当前编辑内容。
